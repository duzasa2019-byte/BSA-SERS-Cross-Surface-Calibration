# BSA-SERS Cross-Surface Calibration

## Research Title
When SERS Calibration Fails Across Surface Chemistries: A Leave-One-Surface-Out Benchmark of Chemometric and Machine-Learning Models

## Author
Hussein Obaid Mashhout

Open Educational College, Dhi Qar Center, Qalat Sukkar Branch, Iraq

Contact: duzasa2019@gmail.com

## Overview
This repository accompanies a computational study of bovine serum albumin (BSA) surface-enhanced Raman spectroscopy (SERS) calibration transfer across four surface chemistries.

The benchmark investigates cross-surface generalization using nested leave-one-surface-out evaluation.

## Methods
- Partial Least Squares (PLS)
- Support Vector Regression (SVR)
- Random Forest (RF)
- Nested leave-one-surface-out validation
- Exploratory vibrational-band analysis
